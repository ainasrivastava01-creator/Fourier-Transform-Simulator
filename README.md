
# Fourier Transform Simulator

An interactive Signals and Systems simulator built using Python and Streamlit.

## Features
- Sine, Cosine, Square and Composite Signals
- Fast Fourier Transform (FFT)
- Magnitude Spectrum
- Phase Spectrum
- Inverse Fourier Transform (IFFT)
- Frequency Detection
- Signal Reconstruction

## Technologies Used
- Python
- NumPy
- SciPy
- Matplotlib
- Streamlit

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Project Objective

To understand Fourier Transform through interactive signal generation, frequency analysis and reconstruction.
